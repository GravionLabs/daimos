---
title: Keyboard
description: Keys of the Daimos window.
---

On macOS use **Cmd** where this page says **Ctrl**.

| Key                         | Action                                                      |
| --------------------------- | ----------------------------------------------------------- |
| **Alt+Space**               | Show or hide the window (configurable).                     |
| **↑ / ↓**, **Home / End**   | Move the selection.                                         |
| **Enter**                   | Run the primary action of the selected result.              |
| **Ctrl+1 … 9**              | Run the n-th visible result.                                |
| **Ctrl+K**                  | Open or close the action panel of the selected result.      |
| **Tab**                     | Show or hide the detail view.                               |
| **Ctrl+,**                  | Open or close the settings.                                 |
| **Esc**                     | Close the panel, go back, clear the query, then hide.       |

In the action panel, **↑ / ↓** choose an action and **Enter** runs it. Applications offer their
own actions (for example a new private window), **Show in file manager** (**Show in Finder** on
macOS) and, on Windows, **Run as administrator**.
